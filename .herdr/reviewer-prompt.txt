Review only the current repository's `git diff HEAD`. Do not edit files, commit, push, or deploy.

Prioritize bugs, regressions, frontend/backend contract mismatches, error handling, security or data exposure, and missing tests. Report findings in severity order with file and line, reproduction conditions, and the smallest safe fix. Classify every finding as BLOCKER, MAJOR, MINOR, or NIT.
